# 课时记账

这是一个给老师用的 iPhone 记账本：记下每个学生上了几节课、这个月该收多少、哪些还没收到。界面是简体中文，金额用 ¥。

数据只存在这台手机里，没有账号，也不会上传到云端。换手机或删掉 App 之前，记录不会自动备份。

## 环境

- Mac，安装 Xcode 16 或更新版本（需要能编译 iOS 17）
- iPhone 系统为 iOS 17 或更新版本
- 一根能传数据的数据线
- 一个免费的 Apple ID（不需要付费的 Apple Developer Program）

工程已经带好 `Keshijizhang.xcodeproj`，用 Xcode 直接打开即可，不必另外安装 XcodeGen。仓库里的 `project.yml` 只是同一份工程的描述，方便以后用 [XcodeGen](https://github.com/yonaskolb/XcodeGen) 重新生成。

## 用 Xcode 打开

1. 把这个仓库下载或克隆到 Mac。
2. 双击 `Keshijizhang.xcodeproj`，用 Xcode 打开。
3. 左边工程导航里点蓝色的工程图标，选中 TARGETS 下面的 **Keshijizhang**。
4. 打开 **Signing & Capabilities**。

## 登录免费 Apple ID，并选中 Team

1. 菜单栏 Xcode → Settings…（旧版叫 Preferences）→ Accounts。
2. 点左下角 `+`，选 Apple ID，登录你的 Apple ID。没有的话用网页或系统设置先注册一个免费账号。
3. 回到 Signing & Capabilities。
4. 勾选 **Automatically manage signing**。
5. Team 里选你的个人团队，名字一般是 `你的名字 (Personal Team)`。
6. 如果 Xcode 提示要注册设备，用数据线把 iPhone 插上，并在手机上点「信任」。

## 把 Bundle Identifier 改成唯一值

免费账号的 Bundle Identifier 不能和别人（包括示例）撞车。现在工程里写的是 `com.example.keshijizhang`，装到真机前要改成只有你用的一串。

在 Signing & Capabilities 的 **Bundle Identifier** 里改掉，例如：

`com.你的名字.keshijizhang`

只用英文、数字和点，不要有空格。改完后如果出现红色的签名错误，等 Xcode 自动注册几秒；仍失败就再换一个没被占用的名字。

## 连接到 iPhone 并运行

1. 用数据线把 iPhone 连到 Mac。如果手机问「要信任此电脑吗」，点信任并输入锁屏密码。
2. Xcode 窗口顶部的运行设备，从模拟器改成你的 iPhone。
3. 点左上角运行按钮（三角形），或按 `Command + R`。
4. 第一次编译会久一点。装好后手机会出现「课时记账」。

## iPhone 上打开开发者模式

iOS 16 及以后，真机调试要先开开发者模式：

1. 打开 iPhone 的 **设置 → 隐私与安全性**。
2. 拉到最下面，打开 **开发者模式**。
3. 按提示重启手机，重启后再确认打开。

如果设置里还没有这一项，先在 Xcode 里对这台手机运行一次，再回设置里找。

## 信任开发者证书

免费签名的 App 第一次点开，会提示「不受信任的开发者」。按这个路径信任：

**设置 → 通用 → VPN 与设备管理**（有的系统写的是「设备管理」或「描述文件与设备管理」）

点你的 Apple ID，再点「信任」。然后回到主屏幕打开「课时记账」。

## 免费签名大约每 7 天要重新运行一次

免费 Apple ID 签出的 App，证书大约 7 天后失效，届时点图标会提示无法验证或无法打开。

处理办法：iPhone 连上 Mac，用 Xcode 再运行一次（`Command + R`）。这是重新签名，不是重装。

只要你没有在手机上删掉「课时记账」，原来记下的学生、课时和收款都还在。删掉 App，本地数据会一起被系统清掉。

## App 里有什么

底部四个标签：

- **今天**：按今天星期列出还没上的固定课和小班，副标题是「还剩 N 节」。点圆圈表示这节上完，这节会马上从待上列表里消失，底部出现「已记录：…上完」，大约 4 秒内可以点「撤销」。已上完的课收在「今天已上完 N 节」里，展开后点一条就能改。下面可以搜索学生，给某一天或连续多天加课、补课；选到以后的日期，要等到那天才出现在今天页待打卡。
- **收款**：按月看未收的课，勾选后确认收款。也可以按学生或机构、用日历选一段日期，一次标成已收。
- **管理**：添加学生、机构、小班，改资料、固定上课时间、停课，以及从某一天起调整后面的单价。点进学生后有「上课记录」，按月查看、修改日期、时间、价格、状态（已上 / 未上 / 请假）、类型和是否已收。改成「未上」后，这节课回到那一天的今天页等待打卡，不计入应收。删除学生前会再问一次。删除机构或小班不会删学生和已经记下的课。
- **月统计**：看这个月应收、已收、未收。可以按学生或按机构汇总，把本月未收一次标成已收。请假的记录显示为不计费。

第一次打开是空的，没有示例学生。先到「管理」添加学生和每节单价。

## GitHub Actions

推送到 `main` 后，GitHub Actions 会在 macOS 上用 Xcode 编译模拟器版本，并额外打一个未签名的 `.ipa` 作为 Artifact，名字是 `Keshijizhang-unsigned-ipa`。

这个 ipa 没有签名，不能直接装进 iPhone。日常安装请用上面的 Xcode 运行。ipa 是留给以后你自己签名用的。
